# Security

Report a vulnerability privately, through the repository's
**Security → Report a vulnerability** page, not in a public issue. Do
not include real payment data or credentials in a report.

This plugin is imported by the pain001 process and runs with that
process's permissions. It reads the files pain001 hands it and keeps
every value as text; validation of the resulting payment happens in
pain001 afterwards.
