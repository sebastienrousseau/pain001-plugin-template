# Security

Report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** facility for this repository, not a public issue. If private
reporting is unavailable, contact the maintainer using the email in
`pyproject.toml`. Do not include real payment data or credentials.

This initial development version generates plugin source, not a sandbox.
Review templates and plugin code before execution: installed plugins inherit
the host process's permissions. Dependencies are locked and audited in CI.
No response SLA or independent security audit is claimed.
