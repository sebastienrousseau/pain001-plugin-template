# pain001-plugin-template v0.0.87

## Highlights ⭐️

* **The example loader is fuzzed**: Atheris runs against the loader every generated plugin starts from, checking that any file either raises `ValueError` or returns rows keyed by the header, and that `load_streaming` yields the same rows as `load`. The tests replay the seed corpus without Atheris.
* **An honest comparison table**: the README and `docs/COMPARISON.md` now compare what a generated plugin gets (a loader on the `pain001.loaders` entry point and tests at 100% line and branch coverage) instead of columns copied from pain001-mockbank.
* **The suite audit runs green again**: Suite Consistency pins the core's ecosystem check at a commit that knows the five pain001 SDK repositories, and runs daily and on dispatch instead of on `workflow_run`.
* **In lockstep with pain001 0.0.87**: the scaffold and the plugins it generates require pain001 0.0.87; generated plugins still start at 0.0.1.

## Details

The scaffold version, CITATION.cff, the README, SUPPORT.md and the bug-report form's placeholder move to 0.0.87 together.
