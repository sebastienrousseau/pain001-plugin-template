# pain001-plugin-template v0.0.86

## Highlights ⭐️

* **Generated plugins start as complete repositories**: a render now ships a README, CHANGELOG, CONTRIBUTING, SECURITY, code of conduct and Dependabot configuration, and its tests cover every refusal path of the example loader at 100% line and branch coverage.
* **Complexity and coverage gates**: `make check` holds the scaffold's scripts and the generated loader to the portfolio's complexity ceilings against an empty baseline, and to 100% coverage.
* **The README Quick Start runs in CI**: `tests/test_readme.py` runs it verbatim, offline, and its last step now calls `python -m pain001` so it uses the environment the plugin was installed in.
* **In lockstep with pain001 0.0.86**: the plugin contract the scaffold targets is unchanged; generated plugins still start at 0.0.1.

## Details

The repository gains its standard layout (governance, support, maintainers, DCO, architecture notes, pre-commit and a devcontainer), issue forms and a pull request template, markdownlint and codespell jobs, and a link check over every Markdown file. The README follows the portfolio template exactly and shows a demo rendered by `make demo`. The scaffold version and README move to 0.0.86 together.
