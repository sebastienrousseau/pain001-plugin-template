# pain001-plugin-template v0.0.83

## Highlights ⭐️

* **In lockstep with pain001 0.0.83**: the scaffold and the plugins it generates require `pain001 >= 0.0.83, < 1`. New third-party plugins still begin at their own version 0.0.1.
* **Same plugin contract**: the loader entry point, the generated tests and the packaging are unchanged from 0.0.82; the core's 0.0.83 work is XML signing and signature verification.
