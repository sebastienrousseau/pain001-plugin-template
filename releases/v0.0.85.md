# pain001-plugin-template v0.0.85

## Highlights ⭐️

* **Generated plugins pass their first CI run**: the generated workflow tested on Python 3.10, which the plugin's `requires-python >=3.11` refuses; it now runs on 3.11 and 3.14, with `actions/setup-python` at the scaffold's own pin.
* **In lockstep with pain001 0.0.85**: the scaffold and the plugin contract it targets are otherwise unchanged; generated plugins still start at 0.0.1.

## Details

Two tests render the scaffold and hold the generated CI to the plugin's supported Pythons and to the action pins Dependabot keeps current in the scaffold's own workflows. The scaffold version and README move to 0.0.85 together.
