# pain001-plugin-template v0.0.82

## Highlights ⭐️

* **First tagged release, in lockstep with pain001 0.0.82**: the scaffold and generated plugins require the released core and Python 3.11 or newer. New third-party plugins still begin at their own version 0.0.1.
* **An installable plugin example**: Cookiecutter produces an entry-point loader with synthetic fixtures and contract tests; integration tests install the generated project and discover it through core.
* **Verifiable source distribution**: the release includes the complete template and documentation, build provenance and asset checksums. Pending pytest, hatchling and filelock updates are integrated into the release branch.
